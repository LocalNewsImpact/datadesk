# Code and documentation review, 2026-09-30

A read of the whole application after the layered map shipped (#425–#427):
the Python, the chart runtime, the tests and CI, and every document against
the code. Nothing here was changed in the review itself; the findings are
ranked so the next pieces of work can be picked off the top. Effort is S
(an hour), M (a day), L (more).

## The shape of the thing

| | |
|---|---|
| Python | 39,000 lines over five apps; largest files `review/views.py` (2,920), `visuals/corpus.py` (2,709), `visuals/views.py` (1,959), `visuals/panels.py` (1,898) |
| Longest functions | `run_story_map` 450 lines, `theme_panel` 308, `review.views.paywalls` 279, `field_panel` 259 |
| Chart runtime | `static/js/datadesk-chart.js`, 4,382 lines / 201 KB unminified, one IIFE; `renderFlowMap` 854 lines, `renderStoryMap` 567 |
| Tests | 153 files, 45,900 lines, 2,933 tests, 89% coverage; 7 min 12 s serially in the pre-push hook |
| Documents | README, SCOPE, ROADMAP (149 KB), REVIEW, seven files in `docs/` |
| Commands | 23 management commands |

Health: deliberately cached and instrumented (`answer_once`, versioned cache
keys, module-level gazetteers, `GridPaginator`), with the reasoning written
beside the code. The risk is concentrated in a few shared choke points and
in writes that take no row locks.

here as the record of what was found.

1. **Tooltips inject payload strings as HTML.** `tip.show` sets
   `innerHTML` and `tipRow` puts values in raw (`datadesk-chart.js`
   ~1871, ~1901). Outlet names, owners, websites, notes, and uploaded CSV
   columns land there. A `<` in a name breaks the tooltip; it is also an
   injection route on embed pages served from the site's origin. Escape in
   `tipRow` and at every `<strong>${…}</strong>`. **S.**
2. **Superusers get empty newsroom counts and empty publisher filters.**
   `ALL_SCOPES` is the string `"__all__"`; `_publisher_rows`
   (`corpus.py:998`) and `newsroom_counts_for` (`views.py:1417`, also
   `:1703`) check `if scopes:` and filter `dataset__slug__in=scopes`, so
   Django iterates the characters. Reached from `views.py:1484` and
   `panels.py:1392` when a visual has no datasets. Treat `scopes is
   ALL_SCOPES` as no filter, as `_base_queryset:861` does. **S.**
3. **Date filters defeat any index on `publish_date`.**
   `publish_date__date__gte/lte` compiles to a timezone cast
   (`corpus.py:911–913`, `outlets.py:235`, `explorer/views.py:261`). Filter
   the raw timestamp as a half-open range instead. **S.**
4. **A resize or theme change wipes reader state.** `mount` redraws on
   width and OS-theme changes; `render` empties the element first, so an
   open table view (and its "View chart" button) is replaced by the chart
   with no way back, and a layered map resets to its first layer with the
   newsrooms back on. Give `mount` a chart/table mode, keep the layered
   map's `active` and `showPoints` outside the renderer, return a
   `destroy()`. **M.**
5. **The layered map runs the whole story map for its coverage**
   (`layermap.py:242`): the points query, the manual merge and the roll-up,
   outside the `"visuals.storymap"` `answer_once` key, then keeps only
   `areas`. Read the areas through the same key, or split out
   `run_story_areas`. **M.**

## Python: performance

6. **The corpus version rebuild stampedes.** On a cache miss every
   concurrent request runs the same seven queries (`corpus.py:2487–2547`),
   two of them `Max()` over unindexed `articles` columns and a count over
   all of `article_geoids`; every cache key depends on it, so everything
   stalls together every five minutes. Guard with `cache.add(lock)` and
   serve the previous stamp while one request rebuilds; ask the crawler
   for indexes on `articles(created_at)` and `articles(entities_extracted_at)`. **M.**
7. **`answer_once` waiters sleep in the request thread** for up to 300 s
   (`corpus.py:2378–2386`), one gunicorn thread each; four slow previews
   hold half the pool, and a waiter past the deadline computes anyway.
   Return 202 and poll, or compute in a job. **M.**
8. **Public `?live=1` is uncached for non-corpus sources**
   (`views.py:333–372`, `services.py:162–166, 219–237`): the outlet map,
   stories, GCS and BigQuery run on every anonymous hit with `no-store`.
   A cost and denial-of-service exposure. Short-TTL cache keyed on
   `(visual.pk, updated_at)`, or corpus-only for anonymous live. **S.**
9. **The story map's shaded layer is truncated without order or notice**
   (`corpus.py:2209–2215`): `[:MAX_RAW_GROUPS]` with no `order_by`, so past
   50,000 rows the counties shaded depend on Postgres's row order and
   `meta` says nothing. Order by id and report `areas_truncated`, or count
   per county in SQL from `article_geoids`. **S/M.**
10. **The enrichment grid loads full article bodies** (`explorer/views.py:638`):
    no `defer` on `text`, `raw`, `text_excerpt` (~200 KB a row); the
    article grid fixed the same at `:228`. **S.**
11. **The visuals index runs up to four permission queries per visual**
    (`views.py:739–745`). Compute the admin flag and scope sets once per
    request. **S.**
12. **Page, public page and embed repeat work**: `_credit_line` twice per
    render, `_attribution` a third time, `_downloads` reloading the pinned
    snapshot's JSON, `may_act_on` twice (`views.py:575, 607–612, 672–681,
    718–719`). Compute once into locals. **S.**
13. **Byline-style pivots run two extra full counts** (`corpus.py:1671, 1803`)
    for informational metadata; one `aggregate` with a filtered `Count`. **S.**
14. **Row-at-a-time imports**: `import_registry` does `update_or_create`
    per outlet (`outlets.py:78–105`), `apply_current([one])` loads every
    current event (`outlet_events.py:263`), the reliability report runs one
    query per variable (`census.py:313`). Fine at 300 outlets and 28
    variables; bulk them before another state's registry arrives. **S–M.**

## Python: correctness and races

15. **`publish()` can pin an empty or unchecked snapshot**
    (`services.py:309–327`): with no snapshot the emptiness check is
    skipped; and the row checked is fetched separately from the row
    pinned. Fetch once, check the object pinned, inside the atomic block. **S.**
16. **Concurrent snapshot captures collide** (`services.py:242–246`):
    `Max("version") + 1` read without a lock, so a keep-updated job and a
    manual Update can both compute the same version and one raises
    `IntegrityError`. `select_for_update` the visual first, or retry once. **S.**
17. **Import-apply and revert read rows one at a time, unlocked**
    (`review/services.py:258–269, 331–341`); a concurrent edit is lost and
    the audit `before` misstates it. `select_for_update().in_bulk()` inside
    the transaction. **S.**
18. **Two concurrent retractions of one event both succeed**: the
    `retracted_by.exists()` check (`outlet_events.py:135`) runs outside the
    transaction. Move it inside and lock the event. **S.**

## The chart runtime

19. **One catch-all turns renderer bugs into "Boundary data unavailable"**
    (~4349, also `renderMap` ~1793), logging nothing; and `fetchJSON`
    caches a rejected promise (~269), so one network blip breaks that URL
    for the page's life, including every resize redraw. Write
    `.then(draw, fetchFailed)`, `console.warn` dropped states, evict on
    rejection. **S.**
20. **Every pointer move over a tract restyles all 1,654 paths** and forces
    a reflow (`isolate` on `pointermove`, ~1913–1921; `innerHTML` rewrite and
    `getBoundingClientRect` in `show`). Isolate on `pointerenter` via a
    class; rewrite the HTML only when the datum changes. **S.**
21. **Every redraw redoes all the map work**: `topojson.feature` re-run on
    the cached JSON (~294, ~307), projection and every path recomputed on a
    layer switch when only fills changed, `spreadCoincident` (~1.1M
    `hypot` calls at 240 points) redone, ResizeObserver undebounced (~25
    redraws dragging through 600 px). Cache features per url+object,
    update fills only on a layer change, memoise the spread per
    (width, points), debounce with `requestAnimationFrame`. **M/L.**
22. **SVG ids collide when two charts share a page**: the story map's clip
    and hatch ids come from width and county count (~4029, ~4036), the
    chord's from a hash of its categories (~3404); the flow map already
    uses a counter (`arrowSeq`). One `uid(prefix)` helper. **S.**
23. **The site's own theme toggle does not redraw charts**: `mount`
    listens to the OS `prefers-color-scheme` only (~4363), while
    `datadesk-theme.js` sets `data-theme`. A `MutationObserver` on
    `documentElement`. **S.**
24. **Flow-map route search inverts every trace point once per county**
    (~3079–3083) inside a SLIDE×CURVE×SIDE×RUN search with no bounding-box
    prefilter. Invert once; skip counties whose bounds miss the trace. **S.**
25. **`renderStoryMap` is 567 lines with dead and repeated code**:
    `roundish` is never called (~4248), one comment appears twice, the
    frame selection repeats the flow map's. Split into `frameFeatures`,
    `storyMapBands`, `countyEdge`, `drawStoryMapSvg`, `rampMarks`,
    `storyMapLegend`; share the first with the flow map. **M.**
26. **Three legend builders, five copies of the font string, two hand-built
    svg roots** (`swatchLegend` ~624, `htmlLegend` ~1948, inline ~4139;
    `svgRoot` ~1968 unused by the flow and story maps). One `swatchItem`
    feeding one `legend()`, a `FONT` constant. **S.**
27. **Every page pays for the whole runtime**: 201 KB unminified, of which
    a table page uses ~900 lines. `builder_edit.html` loads d3, Plot and
    topojson but not d3-sankey (a sankey preview shows "did not load"), and
    passes no `geoUrls`, so the builder downloads unhashed boundary files
    twice. Minify; split into core / plot / d3 / maps chosen by `libs_for`;
    add sankey and `geoUrls` to the builder. **M.**

## Tests and CI

28. **The suite runs serially**: no `pytest-xdist`; 2,933 tests take 7 min
    12 s on every push and again in CI. pytest-django gives each worker its
    own database, so `-n auto` should bring the hook to about two minutes
    on an 8-core machine. Measure in the hook after adding it. **S.**
29. **Renderer tests pin source strings** (`test_a_county_edge_follows_its_fill`,
    `test_the_shading_scale_can_show_a_tail`, `test_the_top_band_is_the_darkest_shade`,
    `test_bands_come_from_the_counties_drawn`, parts of `test_chart_types`):
    they break on any rename and miss real regressions — the first push of
    the layered map was rejected by two of them for a renamed guard, not a
    behaviour change. Once 25 extracts pure helpers, expose them on
    `__test` and assert behaviour through the node harness that already
    exists (`_node` in `test_a_table_is_a_pivot.py`). **M.**
30. **The test suite is larger than the code** (45,900 vs 39,000 lines) and
    one file is 4,893 lines (`test_builder_steps.py`). Not a fault, but the
    walk tests there are where a `-n auto` split pays most.
